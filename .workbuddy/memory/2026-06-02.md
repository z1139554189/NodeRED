## Dashboard 断开修复（第二次）
- **问题**：dashboard.html 更新后看板显示"断开"
- **原因**：6 个 fetch 路径被回退成 `BASE + '/api/v1/...'`（直调 Bridge 8000），应从 Node-RED 走代理 `/api/proxy/...`
- **修复**：全部改回 `PROXY + '/health'` / `PROXY + '/batch-read'` / `PROXY + '/query'` / `PROXY + '/export'` / `PROXY + '/cache-stats'`
- **教训**：每次编辑 dashboard.html 必须检查全部 fetch 路径
