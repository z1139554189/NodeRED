## dashboard.html 自适应路径改造
- **问题**：dashboard.html 频繁被外部更新导致 fetch 路径回退，看板断开
- **根因**：源文件 (OPC-UA-Bridge) 和部署文件 (.node-red) 路径写法不一致，部署时会把有问题的版本覆盖上去
- **修复**：改用自适应 API 路径，同一个文件在 1880 (Node-RED) 和 8000 (Bridge) 下都能工作
- **实现**：检测 `window.location.port`，1880 走 `/api/proxy/...`，其他走 `/api/v1/...`
- **文件**：`.node-red/dashboard.html` + `OPC-UA-Bridge/opcua_api_bridge/dashboard.html` 同步修改
- **结果**：后续从源文件部署不会再引入路径问题
